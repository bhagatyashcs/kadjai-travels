1.Project Title: Kadjai Travels - Tourist Vehicle & Customer Trip Management System
2.Introduction

Kadjai Travels is a modern, enterprise-grade tourist vehicle and customer trip management web platform engineered to modernize tourist transport, intercity cab operations, and private vehicle charter services. Traditional regional travel desks and tourist cab operators operate almost entirely on manual paper booking registers, handwritten cost estimates, unrecorded odometer logs, and post-trip Fastag toll disputes. This leads to customer anxiety over trip pricing, disputed return mileage allowances, lack of driver arrival visibility, and lost customer retention.

Kadjai Travels is a web-based application designed to establish an end-to-end digital lifecycle for tourist transport operations, bridging the communication and operational gap between passengers, commercial drivers, and travel proprietors. The platform enables travelers to estimate accurate trip fares, submit booking enquiries, and track active journey status in real time.

The platform features an automated Multi-Package Fare Engine supporting Outstation Round Trips (with a daily 300 km calendar quota), Outstation One-Way drops, Local City Rentals (8h/80km packages), and Chhatrapati Shivaji Maharaj International Airport (CSMIA) transfers. The system integrates Uber-style live GPS geolocation and forward-geocoding, allowing users to lock any doorstep pickup and destination location across Maharashtra and India.

The application is developed using React 18 and Tailwind CSS for the frontend, Node.js and Express for the REST API backend, SQLite configured with Write-Ahead Logging (WAL) for relational data persistence, and stateless JWT token authentication. The system aims to provide upfront pricing transparency, streamline fleet dispatching, and provide Zero-Login live vehicle tracking for travelers.

3.Objectives

The main objectives of the project are:

  1. To develop a user-friendly web application for tourist vehicle charter and intercity cab bookings.
  2. To allow users to lock pickup and destination locations using live GPS geolocation and geocoding.
  3. To dynamically calculate driving road distances and automatically categorize trip types.
  4. To provide upfront, decimal-safe fare estimation based on verified commercial tariffs (₹25/km).
  5. To maintain pricing transparency by displaying itemized driver charges, Fastag tolls, and parking fees.
  6. To provide a Zero-Login live vehicle tracking portal using booking reference ID and contact phone number.
  7. To provide secure role-based authentication for the fleet proprietor to manage reservations and fleet dispatch.
  8. To maintain real-time fleet availability for the dedicated Maruti Suzuki Ertiga (6+1 AC Luxury) vehicles.

7. Similar Software Study / Background Study

Commercial Cab Aggregators (Ola / Uber Outstation)

Commercial aggregators like Ola and Uber offer intercity outstation cabs and local rentals through mobile applications, operating on commission-based marketplace models with algorithmic driver dispatch.

Similarities with Kadjai Travels:

  • Both systems provide online intercity outstation and local city charter bookings.
  • Both platforms calculate trip fares based on pickup and destination geographic parameters.
  • Both support multiple trip formats, including round trips, one-way drops, and airport transfers.
  • Both provide trip reference codes for customers to follow journey status.

Differences:

  • Kadjai Travels is developed as a custom web-based academic and commercial fleet management project.
  • Kadjai Travels enforces upfront transparent pricing (₹25/KM) with zero dynamic surge pricing.
  • Kadjai Travels manages a dedicated, verified fleet of Maruti Suzuki Ertiga (6+1 AC Luxury) vehicles rather than unvetted third-party market aggregations.
  • Kadjai Travels provides Zero-Login live vehicle tracking by booking reference ID and phone number, eliminating mandatory app installation and account creation friction.
  • Kadjai Travels integrates a full back-office Tourist Vehicle Management System (TVMS) with opening/closing odometer logging and automated printable A4 duty slips.

Kadjai Travels operates as a direct-to-proprietor digital platform with zero third-party commission deductions, designed specifically for regional tourist fleet enterprises.

8.Limitations in Relation to the Proposed Project:
  1. Primary Dedicated Fleet Scope: The operational implementation is optimized for the business's verified tourist vehicle fleet (featuring the 6+1 AC Luxury Maruti Suzuki Ertiga) and does not manage large multi-hub bus depots.
  2. Payment Processing Architecture: Payment settlement registers verified transaction confirmation modes (Cash, UPI QR, and Card) without integrating a third-party payment gateway.
  3. Cellular SMS & GPS Simulation: Real-time journey milestones stream via zero-login web sockets and responsive URLs; live coordinates are simulated via discrete route checkpoints without demanding proprietary in-vehicle OBD GPS black-boxes.
  4. Client-side GPS geolocation accuracy is subject to device hardware precision and user browser location permission approvals.
  5. Forward-geocoding resolution for arbitrary rural locations relies on external OpenStreetMap Nominatim network availability and rate limits.
  6. Opening and closing odometer readings require physical driver reporting and administrative verification upon duty slip generation.
9.Future Scope

The project can be enhanced in the following ways:

1. Automated WhatsApp Notifications: Integrate the WhatsApp Business Cloud API to automatically dispatch live booking confirmations, driver contact cards, and downloadable PDF duty slips directly to customer mobile phones.

3. Driver Native Mobile Application: Develop a dedicated React Native mobile app for commercial drivers featuring 1-tap odometer photo capture, offline GPS checkpoint logging, and digital customer signature pads.
