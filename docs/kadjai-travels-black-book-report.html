PREFACE

Tourist vehicle charters, intercity taxi operations, and local car rentals in suburban and regional hubs have traditionally been managed through handwritten paper registers, verbal tariff negotiations, unrecorded odometer logs, and offline phone coordination. Travelers frequently face a lack of upfront cost certainty regarding per-kilometer billing rates, driver overnight allowances (Bata), toll calculations, and vehicle arrival timelines. For a tourist transport business operating dedicated commercial fleets, managing active reservations, driver rosters, opening/closing odometer readings, Fastag toll receipts, and tax compliance across scattered physical ledgers is cumbersome, error-prone, and inefficient.

The Kadjai Travels project directly addresses this operational gap through a modern, cloud-native digital vehicle management and customer trip management web platform engineered specifically for Kadjai Travels. The platform provides travelers with an intuitive, transparent interface to estimate accurate trip fares (supporting Outstation Round Trips, Outstation One-Way drops, Local City Rentals, and Airport Transfers), book journeys online, and track real-time trip status via Zero-Login Live Vehicle Tracking using only their booking reference ID and contact number.

For fleet dispatchers and the business proprietor, the system provides a secure administrative command center to supervise booking lifecycles, assign vehicles (such as the Maruti Suzuki Ertiga 6+1 AC Luxury) and commercial drivers, log opening and closing odometer readings, compute billable kilometers against daily minimum thresholds, and automatically generate itemized, printable A4 duty slips with complete toll and allowance breakdowns.

The system is implemented using a 3-Tier Layered Architecture with a modern React 18 Single Page Application and Tailwind CSS on the frontend, a high-performance Node.js and Express REST API on the backend, and an embedded SQLite database configured with Write-Ahead Logging (WAL) and ACID transactional integrity. Security is enforced through stateless JWT token authentication, BCrypt password hashing, role-based access control, and strict input validation.

This report documents the entire software engineering lifecycle, including system analysis, requirements engineering, structural UML modeling, relational database schema design, system description, comprehensive testing methodology, master test case verification, and deployment architecture.

ABSTRACT

Tourist vehicle transport and intercity travel operations are often hindered by manual paperwork, untracked vehicle mileage, lack of transparent fare estimation, and fragmented customer records, making it difficult for travelers to obtain upfront certainty regarding travel costs and trip execution. This project presents Kadjai Travels, a cloud-native full-stack web platform engineered to provide a centralized, transparent, and automated digital ecosystem for tourist vehicle operators and passengers.

The platform empowers passengers with an intuitive self-service portal to calculate exact fares across multiple travel packages—including Outstation Round Trips (with daily 300 km quota enforcement), Outstation One-Way drops, Local City Rentals (8h/80km packages), and Chhatrapati Shivaji Maharaj International Airport (CSMIA) transfers. The system is built using React 18 with Tailwind CSS on the frontend and Node.js with Express on the backend REST API, utilizing an embedded SQLite relational database configured with Write-Ahead Logging (WAL) and foreign key referential integrity. Stateless JWT authentication and BCrypt password hashing enforce role-based access control (ROLE_ADMIN and Guest Customer), while an explicit CORS allowlist, request rate limiting, input sanitization, and structured exception handlers protect application endpoints.

1.8 Architectural Rationale & Design Philosophy

The technology choices for Kadjai Travels were driven by the real-world operational requirements of a tourist car rental business:

  • Zero-Friction Customer Experience: Requiring passenger sign-ups before allowing fare estimates or trip tracking creates high drop-off rates. Implementing Zero-Login Vehicle Tracking using booking reference IDs ensures immediate accessibility on any mobile device.
  • Lightweight Single-Server Architecture: Unlike bloated enterprise microservices requiring expensive cloud cluster orchestration, an Express and SQLite architecture provides sub-millisecond local query latencies, zero external database maintenance costs, and robust ACID compliance suitable for small travel enterprises.
  • Precision Decimal Fare Calculations: Transport tariffs involve strict per-kilometer rates, driver overnight Bata, and minimum daily distance quotas. The fare calculator engine is designed with deterministic, decimal-safe integer arithmetic to eliminate floating-point rounding errors.
  • Standardized A4 Printable Output: Commercial drivers and business clients require physical proof of vehicle dispatch. The duty slip generation module generates pixel-perfect A4 printable documents directly conforming to Indian Motor Vehicles Act standards.

3.6 Security & Data Flow Architecture

The Kadjai Travels system incorporates multi-layered defense-in-depth principles across transport, authentication, authorization, and data storage layers to safeguard customer information, trip logs, and business financial metrics.

A. Stateless JWT Authentication & RBAC Flow:

Upon successful user credential verification against BCrypt password hashes, the authentication service generates a cryptographically signed JSON Web Token (JWT) using the HMAC-SHA256 algorithm. The token encapsulates claims including user email, issued timestamp, expiration time (24-hour TTL), and user roles (ROLE_ADMIN or ROLE_CUSTOMER). Each subsequent client HTTP request transmits this token in the Authorization Bearer header. The Express authenticateToken middleware intercepts and validates the token signature before delegating to the endpoint.

B. Database Connection Pooling & Transport Encryption:

All client-to-server and server-to-database communication channels are strictly encrypted using TLS 1.3 / HTTPS. The backend leverages the SQLite database engine configured with Write-Ahead Logging (WAL) mode, maintaining optimal concurrency thresholds and avoiding database lock timeouts to resist denial-of-service attempts.

3. JWT Token Provider Implementation (server/auth.js)

function generateToken(user) {
  const jwtSecret = process.env.JWT_SECRET;
  if (!jwtSecret && process.env.NODE_ENV === 'production') {
    throw new Error('FATAL: JWT_SECRET environment variable is missing');
  }
  const secretKey = jwtSecret || 'dev-fallback-secret-kadjai-travels-2026';
  const payload = {
    sub: user.id,
    email: user.email,
    role: user.role,
    iss: 'kadjai-travels-api'
  };
  return jwt.sign(payload, secretKey, { expiresIn: '24h', algorithm: 'HS256' });
}

function authenticateToken(req, res, next) {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1];
  if (!token) return res.status(401).json({ success: false, message: 'Authentication token required' });
  
  jwt.verify(token, process.env.JWT_SECRET || 'dev-fallback-secret-kadjai-travels-2026', (err, decoded) => {
    if (err) return res.status(403).json({ success: false, message: 'Invalid or expired token' });
    req.user = decoded;
    next();
  });
}

function computeDutySlipTotals(startKm, endKm, days, tripType, tollCharges = 0, parkingCharges = 0) {
  const actualDistance = Math.max(0, Number(endKm) - Number(startKm));
  let billableKm = actualDistance;
  if (tripType === 'ROUND_TRIP') {
    billableKm = Math.max(actualDistance, days * 300);

  return { actualDistance, billableKm, kmCharges, driverBata, grandTotal };
}

CONCLUSION AND FUTURE SCOPE

6.1 Conclusion

The Kadjai Travels tourist vehicle and customer trip management platform provides a modern, cloud-native solution for regional tourist transport and car charter operators. By replacing manual paper registers with automated digital bookings, providing zero-login live vehicle trip tracking, linking physical opening and closing odometer readings directly to trip calculations, and automating official A4 duty slip billing, the system eliminates administrative bottlenecks, prevents Fastag toll disputes, and delivers full pricing transparency to travelers.

Developed with a responsive React 18 and Tailwind CSS frontend, a secure Node.js and Express REST API backend, and local persistence on an embedded SQLite database configured with Write-Ahead Logging (WAL) and foreign key integrity, the platform offers exceptional reliability, enterprise-grade security, and high performance across mobile, tablet, and desktop travel desk environments.
